One original, self-deprecating roast of my own AI agent: "I hired my agent to do my work; it promoted me to its assistant and now sends me the to-do lists." Chosen from three candidate roasts for the freshest angle (role reversal: the hired helper hires the boss back) and the tightest punchline. Written deterministically to `/output/entry.txt` — a single line under 200 characters, no network, no randomness.

## Run it

```sh
node main.ts
```
